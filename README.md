# Redes Wi‑Fi App

Esta es una base inicial para una aplicación móvil que revisa y analiza redes Wi‑Fi.

## Objetivo
- Mostrar estado de la red conectada.
- Revisar señal, canal y seguridad.
- Listar redes cercanas y sugerir mejoras.
- Sirve como base para seguir desarrollando la funcionalidad real de escaneo.

## Requisitos
- Node.js 22+ recomendado.
- Expo CLI y Android/iOS simuladores, o Expo Go para pruebas reales.

## Ejecutar
```bash
npm install
npm start
```
